# Testy i formularz wyników

Historyczne testy: kompilacja Ubuntu/Linux; testowy TrueNAS 25.10.7 na Proxmox; wdrożenie TrueNAS110; według BUILD-INFO z 22.10: regresja PASS, Windows Offline Files PASS. To wystarcza do **zgłoszenia** backportu; inne testy społeczności są opcjonalne.

Scenariusze do opisania przez niezależnych testerów: `smb2.maximum_allowed.read_only_file`, `read_only_dir`, przekierowanie Pulpitu/Dokumentów, Offline Files online/offline/synchronizacja, prawa do zwykłych plików i katalogów, regresje ACL, możliwość odtworzenia testowego środowiska.

W formularzu wyników: wersja TrueNAS, wersja pakietu, klient Windows, opis kroków, oczekiwany/faktyczny rezultat, wycięte z sekretów logi. Nie udostępniaj dokumentów użytkowników ani danych domeny.
